# DATA-STRUCTURES-AND-ALGORITHM
DSA LAB PROGRAMS
Data Structures & Algorithms

A collection of Data Structures and Algorithms (DSA) implementations and problem-solving programs written in C/C++.

This repository covers fundamental concepts such as:

- Arrays and Strings
- Linked Lists
- Stacks and Queues
- Trees and Binary Search Trees
- Graphs
- Hashing
- Searching and Sorting Algorithms
- Recursion
- Greedy Algorithms
- Dynamic Programming

The goal of this repository is to understand how different data structures work, analyze algorithm efficiency, and improve problem-solving skills through practical implementations.

Technologies

- C/C++
- Code::Blocks / VS Code
- Git & GitHub

Purpose

This repository is created for learning, practicing, and building a strong foundation in Data Structures and Algorithms.
